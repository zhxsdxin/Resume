# 在线简历 · Xin Zhang（George Zhang）

单文件、无外部依赖的英日双语简历，可直接用 GitHub Pages 免费托管。两版共用同一套版式，可互相跳转。

## 文件
- `index.html` —— 英文版（Pages 入口）。
- `ja.html` —— 日文版，内容与英文版逐项对应，术语・公司名・日期写法对齐既有職務経歴書。
- 两份都完全自包含：CSS 内联、校徽以 base64 内嵌、无 CDN / 外部字体 / 外部脚本。

## 语言跳转
- 两版 Hero 右上角各有一个「日本語 → / English →」胶囊链接，互相跳转；纯 HTML 相对链接，无需 JS。
- 本地目录对应 `Resume-Xin-Zhang-EN-enhanced.html` ↔ `Resume-Xin-Zhang-JP.html`；本目录对应 `index.html` ↔ `ja.html`。
- 该链接在 `@media print` 中隐藏，导出的 PDF 不带链接，也不影响打印版面。
- **发布时两份文件必须一起推**，只传 `index.html` 的话跳转会 404。

## 与履歴書・職務経歴書的区别
这是和英文版同一套版式的日语 CV（网页），不是日式応募書類：不含生年月日、性别、现住所、证件照、学歴・職歴分栏、志望動機、本人希望栏等固定项目，也不采用職務経歴書的表格体。内容按「専門領域 → 職務経歴 → 学歴 → 語学力 → ベンダー資格 → 国家資格・受賞歴」组织，用于在线展示与投递补充材料；正式応募書類仍用 `履歴書-ZX.docx` 和 `職務経歴書-ZHANG Xin（美化版）.docx`。

## 本地预览
直接用浏览器打开 `index.html`，点 Hero 右上角语言链接即可切到 `ja.html`。
打印 / 导出 PDF：页面不提供打印按钮，用浏览器的 `Cmd/Ctrl + P`，缩放 100%，**务必勾选「背景图形」**（否则浅色底与强调块会丢失）。

## 发布到 GitHub Pages
1. 新建一个仓库（如 `resume` 或 `xin-zhang-cv`）。
2. 把本目录的 `index.html` 与 `ja.html` 一起推到仓库根目录。
3. 仓库 `Settings → Pages → Source` 选 `main` 分支 `/ (root)` → Save。
4. 等一两分钟，访问 `https://<用户名>.github.io/<仓库名>/`；日文版为同目录下的 `ja.html`。

## 配色与版式
- 顶部功能条（打印按钮、8 色配色切换、校徽「标准 / 水印」切换、打印提示）已整体隐藏，页面只保留简历正文与 Hero 右上角的语言链接。
- 功能条的 DOM 仍保留，用于维持默认状态：配色为深蓝 `#2a4e7c`、校徽为标准呈现。需要把这些控件调回来时，把 CSS 里 `.toolbar` 的 `display:none` 改回 `display:flex`。
- 想换配色或水印模式，可临时恢复功能条切换后导出 PDF，或直接在 `:root` 改 CSS 变量。
- 简历正文版式两版一致。

## 联系方式与隐私
- 简历含一个邮箱和两个手机号（日本 / 中国），均为联系用途。
- HTML 源码里这些字符串用数字字符引用编码（`@`、`+`、连字符和部分数字不写成明文）。浏览器渲染、复制、点击 `mailto:` 都正常，只是直接扫源码的正则抓不到完整串。两版一致。
- 这属于轻量处理，能挡住批量扫源码的采集器；会解码 HTML 实体或渲染页面后再读文本的爬虫仍可取到。
- README 与仓库其他文件不重复列出明文联系方式。若需要更强的隔离，可把公开版改成只留邮箱或用单独的联系表单。
- 校徽为院校公开标识；雇主名称为公开信息，简历未含内部系统、密钥或涉密细节。
